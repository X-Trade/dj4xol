Fleet Composition

Subject to change: this page describes the current MVP implementation.

When Composition Is Applied

Fleet composition is assigned when a new fleet is commissioned at a colony with a shipyard. Existing fleets keep their stored values unless they merge with another fleet.

Hull Selection

The game selects the highest unlocked technology with type HULL. That selected hull sets the new fleet's cargo capacity, maximum fuel, starting fuel, and thumbnail class.

Thumbnail class controls art selection. For example, a Freighter hull only draws from the freighter thumbnail folder.

Combat Modifier Selection

The game selects one highest unlocked technology per technology type and then sums offensive and defensive parameters from those selected technologies.

INFRASTRUCTURE technologies are excluded from fleet offensive and defensive stacking. HULL values are included if that hull defines offense or defense parameters.

Propulsion

Maximum safe warp comes from the selected propulsion technology.

Merging Fleets

Merging keeps the thumbnail of the fleet being merged into. Cargo capacity and fuel capacities are summed. Fuel stores are also summed.
