Recent Developments

This is a user-facing summary of recent developments.

v0.12.0

  • Added secret resource interaction with anomolies.
  • Added (un)help(ful) page on secret resources.
  • Tied secret resources into the research tree.

v0.11.0

  • Added secret resources feature.

v0.10.0

  • Made anomoly message more consistent.
  • Show 'due' in red when next turn is due.
  • Cleaned up bombardment and anomoly messages.
  • Styled the join-game panel and added additional helpful information there.
  • Added emails to players when invited to join a new game.
  • Added costs to production panel.
  • Terraforming is now unlocked by research technology.
  • Added capability to have research levels require other categories to have completed a certain level of research.
  • Added spiral-arm galaxy game generation mode.
  • Added email game updates.
  • Reworked lab resource consumption.
  • Added mineral requirements to higher research levels.
  • Fixed mineral consumption for research was all-or-nothing. Now tracks incremental progress.
  • Rebalance tech tree for extended play.
  • Added technology placeholder icons for more technology types.

v0.9.3

  • Added chance for wormhole drive to create unstable wormhole on fleet destruction.
  • Lock scheduled games when turn is due similar to quoroum games that are turned-in.

  • Doubled the fuel consumption of all warp engines.
  • Added fleet capabilities detail section.
  • Fixed wormhole naming.
  • Enabled random events and anomolies by default.
  • Added no-scanners game option (more refined version of original behaviour).
  • Added scanners.
