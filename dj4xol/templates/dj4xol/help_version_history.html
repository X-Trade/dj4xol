Recent Developments

This is a user-facing summary of recent developments.

v0.16.2

  • Fixed advanced scanners were not updating stale encounter reports.
  • Added vague threat response in diplomatic requests.
  • Added ability to trade colonies and reports in diplomatic requests.

v0.16.1

  • Add a server setting for maximum diplomatic requests per race per turn, to prevent abuse. Defaults to 2.
  • Prevent sending a diplomatic request revoked message when it is revoked in the same turn it is sent.
  • Fixed the header in the diplomacy page.

v0.16.0

  • Initial version of the diplomatic requests feature.

v0.15.2

  • Removed intermediate hulls from warmongers.
  • No smart bombs for warmongers.
  • Only scientists get the Prototype Wormhole Drive.
  • Advanced Remote Miners now requires server race type trait: has_advanced_remoteminers.
  • Implemented warp_advantage from server race type traits, gives a fractional boost or cut to effective warp speed.

v0.15.1

  • Added diplomacy to the Play CLI.
  • Cleaned up legacy database migrations repeatedly loading technology tree data from fixtures.
  • Add ability to block certain technologies based on Race Type or Race Type traits.
  • Changed how wormhole drive fleets are merged so their stats are averaged.
  • Rebalanced warp and bomb unlocks.
  • Rebalanced colony scanner ranges and ensure they are all multiples of 5.

v0.15.0

  • Added scanner range race type trait multiplier.
  • Add race type browser to the help index.
  • Use bombardment multiplier from race type.
  • Use starting_colonies from server race type traits in the game joining process.
  • Allow micromanager (Administration) L1 to build up to 1 lab and 1 shipyard, only when all other resource requirements are met.
  • Allow micromanager (Administration) L2 to take ownership of player-created repeat orders for mines, factories, defences, labs, and shipyards in order to optimise jobs, economy and production.
  • Use the race type's ground force multiplier for invasion strength and defending colonists.
  • Conneted up Server Race Type manufacturing multiplier, combat multiplier, defence multiplier, and population growth multiplier.
  • Added server race type browser.
  • Hooked up server race type research multiplier.

v0.14.0

  • Tweaked diplomacy weightings so combate is ever so slightly less likely in cases of Hostile vs anything else.
  • Added server race trait diplomatic profile to encounter combat chance.
  • Added message to the other player when diplomatic stance is changed.
  • Show allied forces as a darker green on the starmap.
  • Process diplomacy changes at the start of turn processing, no intel is revealed or message generated mid-turn.
  • Added diplomacy effects such as shipyard access, shared intel reports, shared scanner ranges, unrestricted resource transfer access, as well as modifiers to combat and colony defence strike chances.
  • Fix production/fleet orders panels refusing to go into a third column in desktop views.
  • Added diplomacy view and basic known-race/default standing parameters.
  • Fixed an issue where no-scanners games would not correctly track other player's fleets.
  • Set default standing to 'hostile' only for existing games to replicate existing behaviour.
