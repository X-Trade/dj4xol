Recent Developments

This is a user-facing summary of recent developments.

v0.12.4

  • Fixed nova bombs not creating asteroid fields, made black hole creation slightly more probable.

v0.12.3

  • Give Fleet order added for transfer or abandonment.
  • Asteroid-field damage now generates a message.
  • Wormhole traversal messages no longer repeat every traversal.
  • Overmax warp damage/destruction now only checks when overmax movement begins.
  • Overmax speed reduction only affects the current order, not repeated copies.
  • Early overmax fuel penalties are higher and stay high until late propulsion.
  • Cleaned up base tech progression Electronics L6 being overpowered.
  • In scanner games, salvage reveals full mineral composition on advanced scan or encounter.
  • In no_scanners games, visiting salvage with basic scanners or better now reveals full mineral composition, since it cannot be owned or otherwise determined.
  • Basic-report thumbnail blur now uses pre-generated blurred image assets instead of CSS blur.
  • Salvage is now globally visible again for games with the no-scanners option enabled.

v0.12.2

  • Salvage now reveals limited information in basic scans.
  • Basic scan of map objects always reveeals a thumbnail and name.
  • Basic scans now produce a blurry thumbnail. Advanced scan or encounter is necessary for the full thumbnail.
  • Salvage is now hidden until it is in basic scanning range, requiring a report to be shown on the starmap.

v0.12.1

  • Stop fleets from following targeted enemy fleets that have moved out of sensor range.
  • Prevent potential unsporting gameplay data leaks in the Play CLI's detail command.
  • Added strict origin checking for Play CLI's API.
  • Added 'own' and 'other' filtering for /fleets command in Play CLI.
  • Added cleaner mapobject link text representation in Play CLI.
  • Added /rename and /notes commands to Play CLI.
  • Added ability to search for objects by name (using quotation marks) in the Play CLI.
  • Extended Play CLI help commands and subcommands.
  • Added Web Play CLI for regular desktop players to access a text based interface to their game.
  • Added /reports (known objects) list and /status (turn status) commands to the Play CLI.
  • Added salvage and anomales listing to the Play CLI.
  • Added test email admin action.
  • Rebalanced anomaly decay with stability based decay probability.
  • Rebalanced anomaly spawning with count/cap based spawn probability.
  • Added a message when a fleet was targeting an anomaly that has been removed.
