Recent Developments

This is a user-facing summary of recent developments.

v0.9.1

  • Removed wormhole drive speed from intercept and patrol orders.
  • Added wormhole drive.
  • Added bombs and bombing runs. Added remote-mining technology and orders
  • Added the 'play' CLI for future basic LLM based AI player integration
  • Added chance and luck scaling to offence and defence in combat
  • Added starship hull designer (server admin tool).

v0.9.0

  • Added email preferences.
  • fixed tooltips so they render on top of everything else
  • added tech level evaluation for starting fleets. Fixed a bug that caused the detail panel to disappear.
  • Added colony production orders complete message.
  • Added colony infrastructure to stored reports. Corrected production summary messaging.
  • Hide 'jobs' from reports on other player's colonies. Show fleet composition when encountering another player's fleet. Prevent duplicate first contact messages from the same encounter. Corrected formatting of first contact and combat message locations.
  • styled login form.
  • corrected some messages did not link to relevant fleets or locations corrected priority of colonization and scuttling messages was reversed added landing/home page.
  • completely rebuilt themes and styles.

v0.8.7

  • Tightened up the margins in the win95 theme. Moved the Messages panel to the bottom of the page in mobile/1-column layouts.
  • Added missing repeat button to production orders.
  • increased maximum mobile view panel height to 75%.

v0.8.6

  • improved interception and combat-locking mechanics
  • fixed yield depletion was not effective
  • Allow changing repeat on existing fleet orders in list. Show expected duration on tooltips for movement orders. Balanced fuel consumption and combat modifiers when merging fleets.

v0.8.5

  • Added starting tech-levels for race and maximums in game setup.
  • Fixed Frigate hull class using the wrong thumbnails.
  • Added path display toggle for visualising fleet movements in the starmap.
  • Added toggleable star names in the starmap.
  • Added patrol radius visualisation to the starmap.

v0.8.4

  • Introduced level-0 baseline fleet technology.
  • Added technology thumbnails and hover/zoom interactions.
  • Expanded hull and propulsion technology tree.

v0.8.3

  • Refreshed default technology balancing.
  • Patched migration compatibility.

v0.8.1

  • Added deterministic fleet and star thumbnails.
  • Added fleet fuel systems.
  • Introduced hull-driven cargo and fuel capacities.

v0.8.0

  • Added fleet combat technology.
  • Added race creation research options.
  • Improved colony production messaging.
  • Added hazard fire from hostile planetary defences.

v0.2.2

  • Rolled out research categories and unlocks.
  • Added the Technology Directory.
  • Added help pages for combat, invasion, and core systems.

v0.2.0

  • Introduced space combat and invasion rules.
  • Added staffing-aware economic and defence calculations.
  • Improved map controls on mobile and desktop.
  • Refined messaging, detail panel, and turn flow.

v0.1.2

  • Added first-time user experience pages.

    v0.1.1

    • Established the core gameplay loop.
    • Added player and game setup.

    • Added production queues, mining, factories, and shipyards.
    • Added reports, themes, and major responsive UI structure.
