Recent Developments

This is a user-facing summary of recent development. Some historical version markers are approximate because formal release tracking started later in the project.

v0.8.4

  • Introduced level-0 baseline fleet technology.
  • Added technology thumbnails and hover/zoom interactions.
  • Expanded hull and propulsion technology tree depth.

v0.8.3

  • Refreshed default technology balancing.
  • Patched migration compatibility.

v0.8.1

  • Added deterministic fleet and star thumbnails.
  • Added fleet fuel systems.
  • Introduced hull-driven cargo and fuel capacities.

v0.8.0

  • Added fleet combat technology.
  • Added race creation research options.
  • Improved colony production messaging.
  • Added hazard fire from hostile planetary defences.

v0.2.2

  • Rolled out research categories and unlocks.
  • Added the Technology Directory.
  • Added help pages for combat, invasion, and core systems.

v0.2.0

  • Introduced space combat and invasion rules.
  • Added staffing-aware economic and defence calculations.
  • Improved map controls on mobile and desktop.
  • Refined messaging, detail panel, and turn flow.

v0.1.2

  • Added first-time user experience pages.

    v0.1.1

    • Established the core gameplay loop.
    • Added player and game setup.
    • Added stars, fleets, and movement orders.
    • Added production queues, mining, factories, and shipyards.
    • Added reports, themes, and major responsive UI structure.

    v0.0.1

    • Earliest playable prototype from 2021.
    • Included basic game setup and fleet movement foundations.
